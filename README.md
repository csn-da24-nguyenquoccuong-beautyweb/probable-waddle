## 📖 Mô tả đề tài

Đồ án xây dựng một website giúp quản lý và đặt lịch dịch vụ làm đẹp.
Người dùng có thể đặt lịch online, xem dịch vụ, trong khi quản trị viên có thể quản lý khách hàng, lịch hẹn và dịch vụ.

---
## ⚙️ Công nghệ sử dụng
- Frontend: HTML, CSS, JavaScript
- Backend: NodeJS + ExpressJS
- Database: MySQL
  
---
## 🚀 Chức năng chính

### 👤 Người dùng

* Đăng ký / đăng nhập
* Xem danh sách dịch vụ
* Đặt lịch làm đẹp
* Xem lịch đã đặt

### 🛠️ Quản trị viên

* Quản lý dịch vụ
* Quản lý khách hàng
* Quản lý lịch hẹn
* Thống kê cơ bản

---

## ▶️ Hướng dẫn chạy dự án

1. Clone repository về máy
2. Cài đặt các thư viện cần thiết
3. Kết nối database
4. Chạy project
